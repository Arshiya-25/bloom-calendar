# Bloom Planner 🌸

A minimal, aesthetic calendar and planning app built with React.  
Designed to manage daily events, notes, and date ranges with a clean UI.

## Features

- Monthly calendar view
- Add, edit, and delete events
- Range selection with notes
- Theming support (dark/light + accents)
- Local storage persistence
- Smooth modal-based interactions


## Tech Stack

- React
- Vite
- JavaScript (ES6+)
- CSS (custom styling)

- src/
components/

- App.jsx
- main.jsx



## Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/bloom-planner.git
cd bloom-planner
```

Install dependencies:
```bash
npm install
```

Run the development server:
```bash
npm run dev
```
